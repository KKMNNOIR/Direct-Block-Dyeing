# 概要
羊毛やテラコッタ、コンクリートなどの色付きブロックを染料で右クリックすることで直接色をつけることができます。

# 対応バージョン
26.3~

# 対応しているもの
以下のブロックが染色できます。

* 羊毛
* 羊毛ハーフブロック
* 羊毛階段
* カーペット
* コンクリートパウダー
* コンクリート
* コンクリートハーフブロック
* コンクリート階段
* テラコッタ
* 色ガラス
* 色付き板ガラス
* シュルカーボックス
* ベッド
* ろうそく

# 対応していないもの
以下のブロックには対応していません。

* 彩釉テラコッタ
* 旗
* ろうそくを立てたケーキ

上記の他、
クッションとシュルカーといったエンティティや狼の首輪、ハピガスのハーネス、革装備などの装備、バンドルといったアイテムも対応していません。

# その他注意？
本データパックでは染料が一律でこういう挙動になります。
染料を(コマンドの媒体等)何らかの理由で使っているデータパックとの相性は保証しません。
