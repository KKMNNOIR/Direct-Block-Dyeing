# 概要
羊毛やテラコッタ、コンクリートなどの色付きブロックを染料で右クリックすることで直接色をつけることができます。

# 対応しているもの
以下のブロックが染色できます。

* 羊毛
* 羊毛ハーフブロック
* 羊毛階段
* カーペット
* コンクリートパウダー
* コンクリート
* コンクリートハーフブロック
* コンクリート階段
* テラコッタ
* 色ガラス
* 色付き板ガラス
* シュルカーボックス
* ベッド
* ろうそく

# 対応していないもの
以下のブロックには対応していません。

* 彩釉テラコッタ
* 旗

上記の他、クッションとシュルカーはエンティティの為対応していません。
犬の首輪やハピガスのハーネス、革装備といったものも似たような理由で対応していません。

# その他注意？
本データパックでは染料が一律でこういう挙動になります。
染料を(コマンドの媒体等)何らかの理由で使っているデータパックとの相性は保証しません。
